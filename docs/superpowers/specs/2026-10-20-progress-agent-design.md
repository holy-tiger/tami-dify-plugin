# 可感知迭代预算的 Agent 策略插件

## 目标与选择

创建独立插件 `tami/progress_agent`，基于本仓库官方 `cot_agent` 的 Function Calling 实现，让模型获知当前轮次、剩余预算，并在检查点评估进展、改变方法或向用户补充提问。用户已在对话中确认独立插件、动态参数及创建插件的方向。

插件每轮只注入预算状态和检查点标记，进展检查与收尾行为由 Agent 节点的 `instruction` 配置，推荐指令写在插件目录的 `README.md` 中。不增加单独的评审模型调用，轮次含义明确。独立评审调用更可控但会增加成本；程序化识别重复调用适合后续按实际运行记录补充，本版不以重复调用直接判定阻塞。

## 参数与变量

保留官方模型、工具、指令、查询、文件、检索上下文及工具允许列表输入。四个预算参数声明为 `string` 且 `template.enabled: true`，可填写常量或引用 Chatflow 变量，插件接收解析后的值再严格转为整数：

| 参数 | 默认值 | 约束 |
| --- | --- | --- |
| maximum_iterations | 30 | 1..500，总模型调用轮数上限 |
| progress_check_start | 20 | 1..maximum_iterations，首次检查轮次 |
| progress_check_interval | 5 | 1..500，检查间隔 |
| final_response_rounds | 1 | 1..maximum_iterations，尾部禁止工具调用的轮数 |

接受整数、整数形式的字符串及整数数值的浮点输入；拒绝布尔值、小数、空字符串、未解析模板。检查起点必须不超过总预算；落在收尾阶段的检查不再执行，以收尾优先。不传检查起点时，按总预算自动收缩默认起点；若 Dify 已传入默认值 `20`，则按显式输入校验，缩小预算时需同时调整检查起点。

## 执行流程

1. 调用模型前校验所有参数，复制输入历史，避免改变运行时提供的历史对象。
2. 每轮从程序计数生成预算状态：本轮编号、总上限、本轮后的剩余轮数、仍可执行工具的轮数、是否检查点、是否收尾阶段。
3. 将最新状态以 `<iteration_budget>` JSON 块附加到当轮系统指令，不添加固定的进展检查、提问或收尾行为提示，不将旧预算状态累计到历史中，不打断 assistant/tool 消息配对。在 token 预算重算前注入。预算模块只负责校验与计算，模型调用层负责状态序列化和注入。
4. 检查点为 `start + n * interval`，且必须在工具可用阶段，届时仅设置 `is_checkpoint=true`。用户在 Agent 节点中配置推荐指令，引导模型评估完成事项、未完成事项、阻碍与下一步；无实质进展换方法，缺少用户信息时提问，正常推进则继续。
5. 允许任何轮次提前回答或提问；是否检查进展及如何判断由用户配置的 Agent 指令和模型表现决定，不声明可确定检测所有阻塞，不要求输出完整内部推理。
6. 收尾阶段设置 `is_finalization=true`，不再向模型提供工具，并由程序拒绝模型仍然返回的工具调用。如何总结、是否提问等规则来自 Agent 指令。首个有效最终回答即结束，不为用满预算而多次总结。
7. 总轮数包含收尾调用，绝不额外调用模型。预算为 1 时只回答或提问，不执行工具。违规的工具请求或空白最终回答产生明确兜底提示，避免静默退出。
8. 保留官方工具文件转发、允许列表、历史、多模态与检索引用行为；输出官方费用元数据及迭代元数据，供日志和下游读取。

默认例子：第 20、25 轮为检查点，第 1..29 轮可调用工具，第 30 轮仅回答；某轮可并行请求多个工具，因此轮数不等于工具数量，也不代表任务完成比例。

## 用户补充信息与续接

本版通过最终文本提出问题并结束当前 Agent 执行，不实现原地暂停/恢复。用户下一条消息重新运行 Chatflow；应启用节点历史消息，并通过指令引用会话变量保存的进度摘要。预算每次节点调用重新计数，插件不持久保存局部状态，不保证历史自动保留所有工具结果。

## 独立性与交付

目录 `agent-strategies/progress_agent`，独立 manifest、provider 和 strategy 标识，作者 `tami`，版本 `0.0.2`。将所需官方运行代码随插件复制，运行时不依赖相邻 `cot_agent` 目录。采用自定义 SVG 图标、Python 3.12、锁定依赖，在 `README.md` 和 `README.zh_Hans.md` 提供中文使用说明及推荐 Agent 指令，并提供无真实密钥的远程调试配置示例。官方插件文件不变。
